# Cancer Awareness & Support – Web Page  
A simple, responsive web page built as an internship assignment.  
This project spreads awareness about cancer and includes a clean UI with a contact form and a real-time motivational quote section.

---

## ✅ Features
- 🌸 **Landing Page** with banner image  
- ✉️ **Contact Form** (Name, Email, Message) — *no backend required*  
- 📱 **Fully Responsive Layout**  
- 🔄 **Real-Time Quotes Section** using a public API  
- 🎨 Simple, clean design suitable for beginners

---

## ✅ Tech Stack Used
- **HTML**
- **CSS**
- **JavaScript (Fetch API)**
- **GitHub Pages** for hosting
